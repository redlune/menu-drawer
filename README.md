# 메뉴 서랍 | Menu Drawer

macOS 메뉴 막대에서 자주 쓰지 않는 앱 아이콘을 작은 서랍에 모아 두는 유틸리티입니다. 서랍에서 앱 아이콘을 누르면 해당 앱의 원래 메뉴가 열립니다.

- ⌘ 드래그나 아이콘 배치 창에서 숨길 앱을 선택합니다.
- 서랍 바깥을 클릭하면 닫힙니다. 펼친 아이콘을 일정 시간 뒤 자동으로 접을 수도 있습니다.
- 한국어와 영어를 지원하며 macOS의 앱별 언어 설정을 따릅니다.

## 다운로드

**Apple Silicon Mac과 macOS 27 이상**이 필요합니다. GitHub의 **Releases**에서 `MenuDrawer-…-macOS-arm64.dmg`를 받으세요.

현재 배포판은 로컬 서명으로 빌드한 미리보기입니다. 다운로드한 앱의 실행이 차단되면 같은 릴리스에서 소스 ZIP을 받아 아래 빌드 절차를 따르세요.

## 설치 및 사용

1. DMG를 열고 `MenuDrawer.app`을 이미지 안의 **Applications** 바로가기에 끌어 놓습니다. 직접 빌드했다면 `.build/MenuDrawer.app`을 **응용 프로그램** 폴더로 옮깁니다. 설치한 앱을 실행합니다.
2. **손쉬운 사용**을 허용한 뒤, 메뉴 막대에서 **⌘를 누른 채** 숨길 아이콘을 서랍 버튼 바로 왼쪽으로 끌어 놓습니다. 서랍의 **… → 아이콘 배치**에서 **메뉴 막대**와 **서랍** 사이로 아이콘을 끌어 옮길 수도 있습니다.
3. 메뉴 막대의 **서랍 버튼**을 누르면 바로 아래에 앱 아이콘이 한 줄로 나타납니다. 아이콘을 클릭하면 해당 앱의 원래 메뉴가 열립니다. 메뉴를 자동으로 열려면 **시스템 설정 → 개인정보 보호 및 보안 → 기기 제어 및 데이터 접근**에서 **MenuDrawer**를 허용하세요.
4. 서랍 끝의 **… → 아이콘 배치**에서 앱을 메뉴 막대 쪽으로 끌어 놓으면 다시 고정됩니다. **… → 모든 아이콘 펼치기**로 원래 아이콘을 잠시 표시할 수도 있습니다.

앱 선택과 자동 접기 시간은 Mac에 저장됩니다. 앱이 아이콘을 여러 개 제공하면 함께 숨겨집니다. 서랍에 넣을 때 원래 아이콘을 메뉴 막대 왼쪽 끝에 배치하므로 이때 이동이 보일 수 있습니다. 이후 서랍에서 앱을 선택하면 그 자리에서 아이콘과 메뉴가 열립니다.

**손쉬운 사용**은 메뉴 막대에서 드래그할 대상을 확인하고 숨긴 앱의 원래 메뉴를 여는 데 사용합니다. 화면 기록 권한은 필요 없습니다. 메뉴 열기에 실패한 경우 **…** 버튼에 안내가 표시됩니다. 로컬 서명 빌드를 업데이트한 뒤 손쉬운 사용이 작동하지 않으면, 시스템 설정에서 기존 MenuDrawer 항목을 제거하고 응용 프로그램 폴더의 새 설치본을 추가하세요.

한국어와 영어를 지원합니다. 이 앱의 언어만 바꾸려면 **시스템 설정 → 일반 → 언어 및 지역 → 응용 프로그램**에서 메뉴 서랍을 추가하고 언어를 선택한 뒤 앱을 다시 여세요.

## 빌드

macOS 27과 macOS 27 SDK가 포함된 Xcode가 필요합니다. 프로젝트 폴더에서 다음을 실행합니다.

```sh
bash ./build.sh
```

`.build/MenuDrawer.app`에 로컬 서명된 Apple Silicon 앱을 생성합니다. 별도 인증서로 빌드할 때는 `SIGN_IDENTITY`를 지정합니다.

## macOS 호환성

아이콘 숨기기는 macOS 27의 비공개 메뉴 막대 프레임워크를 사용합니다. macOS 업데이트가 이 동작을 바꿀 수 있습니다. 서랍이 접혀 있는 동안 집중 모드·지금 재생 중 등 일부 시스템 항목과 시계 클릭을 통한 알림 센터 열기가 제한될 수 있습니다. 서랍을 펼치거나 앱을 종료하면 표시 제한을 해제합니다. [macOS 27에서 확인된 시스템 동작](https://github.com/dwarvesf/hidden/pull/438)
